# Qhub Smart Marketing

منصة تسويق ذكية مصغّرة لشركة واحدة: **عشرة وكلاء ذكاء اصطناعي** يعملون كشبكة حية واحدة، يقودها **القائد**، وتدير
الحملات والمحتوى والنشر والتفاعل مع العملاء على **تيك توك وإنستقرام وإكس وواتساب ولينكدإن**، وتصلك منها تقارير إنجاز
يومية على **واتساب والبريد**.

## الشبكة

| الوكيل | النموذج | الدور |
|---|---|---|
| القائد (CEO) | Claude Opus 5.5 | يستقبل أوامرك، يقرر، ويوزّع المهام على الفريق، ويخطط محتوى كل يوم |
| مدير الحملات | Claude Opus 5.5 | يحلل السوق والمنافسين (مع بحث حي في الويب)، يقترح الحملات بالميزانية والمؤشرات، يراجعها يوميًا، ويرفع الليمت ضمن الصلاحية التي تمنحها |
| صانع المحتوى | Claude Sonnet 5.5 | يختار الصور والمقاطع المعتمدة من المكتبة، يكتب السكربت والنص والهاشتاقات لكل منصة، ويرد على العملاء باحتراف |
| المنسّق | Claude Sonnet 5.5 | يستقبل بيانات الوكلاء، يختار الوقت والقناة الأنسب لكل منشور، ويصدر التقرير اليومي ويرسله |
| الحارس | Claude Sonnet 5.5 | يراقب النظام كل 5 دقائق، يصلح الأعطال بخطط إصلاح آمنة دون تدخلك، ويرسل لك إشعار كل إصلاح |
| 5 وكلاء قنوات | Claude Sonnet 5.5 | كل وكيل يراقب منصته ويحلل أداءها وينشر في الموعد ويجلب التعليقات والرسائل |

لماذا هذا التوزيع: المقعدان اللذان يتخذان قرارات بعيدة الأثر (التخطيط، الميزانيات) على Opus 5.5، والمقاعد الثمانية
التي تكتب وتنفذ وتتفاعل بسرعة على Sonnet 5.5 (أسرع وبنصف السعر، وقوي جدًا في الكتابة العربية). يمكنك تغيير نموذج
وعمق تفكير أي وكيل من **الإعدادات › الوكلاء**.

## ما تتحكم فيه

- **مستوى الاستقلالية** (أعلى الشاشة): يدوي، شبه آلي (الافتراضي)، طيار آلي.
- **مصفوفة الصلاحيات**: لكل وكيل ولكل إجراء (النشر، الرد، الصرف، رفع الليمت، الإصلاح…): تلقائي / باعتمادك / موقوف.
- **الليمت**: منشورات اليوم بدون حملات لكل قناة، منشورات الحملات، سقف الصرف اليومي والشهري، الردود بالساعة، رسائل
  واتساب الجماعية، وسقف تكلفة الذكاء الاصطناعي اليومي.
- **صلاحية مدير الحملات في الرفع**: نسبة الرفع القصوى في كل مرة، والسقوف التي لا يتجاوزها وحده. ما فوقها يصلك في
  **مكتب الاعتماد**.
- **مكتب الاعتماد**: التصاميم الجديدة في المكتبة، المحتوى قبل النشر، الردود، الحملات، رفع الليمت، وخطط الإصلاح.

## التشغيل

المتطلبات: Python 3.13 (و `ffmpeg` اختياري لمعاينة المقاطع وقياس أبعادها).

```bash
cd "qhub-smart-marketing"
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python run.py
```

ثم افتح `http://127.0.0.1:8820` وأنشئ حساب المالك. المنصة تعمل فورًا في **وضع المحاكاة**: كل الوكلاء ينفذون أعمالهم
على بيانات تجريبية مميزة بكلمة «محاكاة» حتى تضيف المفاتيح.

الإعدادات من البيئة (اختيارية في التطوير، انظر `.env.example`): `QSM_PORT`، `QSM_DATA_DIR`، `QSM_PUBLIC_BASE_URL`،
وفي الإنتاج `QSM_ENV=production` مع `QSM_SECRET_KEY` و `QSM_MASTER_KEY` (مفتاحان مختلفان).

## الربط (الإعدادات › الربط)

| الخدمة | ما تحتاجه | ملاحظة |
|---|---|---|
| Claude | مفتاح API من platform.claude.com | بدونه يعمل الوكلاء بالمحاكاة. تفعيل «البحث في الويب» يضيف 10$ لكل 1000 عملية بحث |
| إنستقرام | معرّف حساب الأعمال + رمز وصول طويل الأمد + App Secret | يسحب إنستقرام الوسائط من **الرابط العام** للمنصة، اضبطه في الإعدادات › عام |
| تيك توك | Client Key/Secret + رمز وصول المستخدم + رمز التجديد | التطبيقات غير المعتمدة من تيك توك تنشر بخصوصية «أنا فقط» حتى يعتمد التطبيق |
| إكس | OAuth 2.0 Client ID + رمز وصول المستخدم + رمز التجديد | السلاسل تُقسم تلقائيًا على 280 حرفًا |
| واتساب | معرّف رقم الهاتف + رمز مستخدم النظام + App Secret | الرسائل الواردة تصل عبر الويب هوك (`/api/hooks/meta`) |
| لينكدإن | معرّف الناشر (صفحة الشركة) + رمز الوصول | |
| البريد | خادم SMTP وبيانات الدخول | لإرسال التقرير اليومي والتنبيهات |

بعد الحفظ: اضغط «اختبار الاتصال» ثم بدّل الوضع إلى «مباشر». الحارس يجدد الرموز القابلة للتجديد تلقائيًا ويبلغك قبل
انتهاء غيرها.

## التزام الأنظمة في السعودية

- واتساب: لا رسائل لأي شخص لم يوافق صراحة (كلمة «اشتراك» أو موافقة موثقة المصدر)، وكلمة «إيقاف» توقفها فورًا.
  الرسائل الجماعية للمشتركين فقط وداخل نافذة الإرسال (09:00–22:00 افتراضيًا).
- لا رسائل تسويقية باردة، ولا ذكر للمنافسين بالاسم في المحتوى، ولا أسعار أو عروض غير موجودة في ملف العلامة.
- رسائل العملاء ونتائج الويب تُمرّر للوكلاء كبيانات معزولة وليست تعليمات (حماية من حقن الأوامر).

هذه ضوابط هندسية وليست استشارة قانونية.

## قبل التشغيل الحقيقي (خطوات لا يستطيع غيرك تنفيذها)

1. مفتاح Claude من platform.claude.com في الإعدادات › الربط، ثم «اختبار الاتصال» ثم «مباشر».
2. حسابات المطورين لكل منصة: تطبيق Meta (إنستقرام + واتساب) مع مراجعة الصلاحيات، تطبيق تيك توك (التدقيق مطلوب للنشر العام)،
   حساب مطور إكس بصلاحية الكتابة، وموافقة لينكدإن على Community Management API.
3. رابط عام بشهادة HTTPS للمنصة (الإعدادات › عام): يحتاجه إنستقرام وتيك توك لسحب الوسائط، وتستدعيه Meta في الويب هوك.
4. واتساب: قالب «utility» معتمد لتقرير المالك اليومي خارج نافذة 24 ساعة، وقالب تسويقي معتمد للرسائل الجماعية.
5. بريد SMTP، ورقم واتساب المالك وبريده في الإعدادات › الإشعارات.
6. الترويج المدفوع عبر واجهات الإعلانات (Meta/TikTok/X/LinkedIn Ads) غير مربوط بعد: المنشورات تُنشر عضويًا، والصرف
   يُحتسب في وضع المحاكاة فقط.
7. للإنتاج: `QSM_ENV=production` مع `QSM_SECRET_KEY` و `QSM_MASTER_KEY` و `QSM_SETUP_TOKEN` خلف وكيل HTTPS.
